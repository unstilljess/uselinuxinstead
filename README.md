## Nvidia Drivers
Nvidia is a *wonderful* company full of proprietary, closed source blobs, and code that becomes fundementally incompatible with new software.

While using *Linux* is generally compatible with outdated hardware, using a graphics card that was recently out of date is a quick way to ensure that your modern distribution is unsupported. This will crash X and Wayland due to incompatible drivers.
